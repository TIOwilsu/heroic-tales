# 15 — Development roadmap

This is a plan, not permission to execute all tasks. Execute one explicitly requested task at a time.

## Phase 1 — Foundation

Objective: establish repository conventions and minimal Next.js/NestJS/MongoDB boundaries. Dependencies: none. Tasks: 00–03. Expected result: documented, runnable foundations without product behavior. Completion: foundations are testable and decisions are recorded.

## Phase 2 — Identity and character core

Objective: support ownership and character drafts. Dependencies: Phase 1; authentication decision. Tasks: 04–05. Expected result: secure user-owned character persistence. Completion: authorization and resume tests pass.

## Phase 3 — Guided creation

Objective: deliver the seven-stage wizard and dashboard. Dependencies: character core and UI decisions. Tasks: 06, 12. Expected result: users can create, save, resume, edit, and approve stories. Completion: critical wizard journey passes.

## Phase 4 — AI and media

Objective: integrate contextual suggestions, stories, approved-source images, and board-ready character tokens. Dependencies: security, provider, moderation, storage, cost, and token-format decisions. Tasks: 07–10. Expected result: explicit user-controlled AI workflows and downloadable visual assets. Completion: provenance, failure, safety, approval, and token-source tests pass.

## Phase 5 — Knowledge, quality, release

Objective: establish permitted D&D knowledge handling and production readiness. Dependencies: licensing/legal decisions and prior phases. Tasks: 11, 13, 14. Expected result: tested, deployable product baseline. Completion: release checklist and operational ownership are approved.
